# Might and balance

[All documentation](../README.md)

Might values overall power under declared reference conditions. Tier follows
from Might; comparisons are made within a family such as spells or weapons.

## Current references

| Document | Purpose |
| --- | --- |
| [Might assessments v2](assessments.md) | Current Estimated values for all 138 definitions, developed-build assumptions and per-family evidence. |
| [Game library](../features/library.md) | How Might, tiers, assessment status, sorting and filters appear to players. |
| [Might specification](spec.md) | Accepted model and Library requirements from issue #4. |

The v2 assessment links to [spell previews](assessments/spell-previews-v2.json),
[passive probes](assessments/passive-probes-v2.json) and
[enemy probes](assessments/enemy-probes-v2.json). These support authored judgments;
they do not calculate Might automatically or establish completed balance
calibration.

## Research and calibration

- [Calibration](calibration.md): promotion thresholds, the first reference
  proposal and controlled combat observations. Current assessment conditions are
  defined in v2 above.
- [Engine probe notes](calibration/engine-probes.md) and
  [recorded results](calibration/engine-results.json): reproduction commands,
  measurements and limits for the initial calibration.
- [Might and tier research](research.md): design precedents, power budgets and
  special-effect tradeoffs. Numerical examples are research proposals.
